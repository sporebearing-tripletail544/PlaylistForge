## 💡 Troubleshooting common issues

If the application behaves in an unexpected way, check these common fixes.

* **Application does not open:** Ensure you are using the .exe version specifically built for Windows. Check that your antivirus program is not blocking the file.
* **Playlist link fails:** Check your internet connection. Confirm the playlist is set to public on YouTube. Private playlists do not work with this tool.
* **Slow performance:** Large playlists with hundreds of entries take more time to load. Please wait for the progress bar to finish before you attempt to export data.
* **Formatting errors:** If your spreadsheet software does not read the CSV file correctly, ensure your computer locale settings match the file format.
